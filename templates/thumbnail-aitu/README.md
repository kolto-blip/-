# Шаблон превью «AITU / стипендия»

- `original.webp` — исходная картинка (1242×692).
- `template.html` — редактируемая версия макета: откройте в браузере, поменяйте текст и картинки.

## Структура макета

| Элемент | Где | Стиль |
|---|---|---|
| Заголовок, строка 1 | низ по центру | белый, Oswald Bold, капс, чёрная обводка |
| Заголовок, строка 2 | под первой | жёлтый `#ffd21f`, тот же стиль |
| Герой (фото) | слева, до низа кадра | PNG без фона, `--person-image` |
| Фон | весь кадр | здание + тёплое свечение слева, `--bg-image` |
| Формулы | поверх фона | светящийся курсив |
| Логотипы AITU | левый верх и левый низ | белая плашка с наклоном |
| Шапки выпускника 🎓 | правый верх и правый низ | эмодзи/стикер |

Чтобы сделать новое превью: замените `--bg-image`, `--person-image` и две строки в `.title`.

## Вариант «Нұртілек»

- `thumbnail-nurtilek.png` — готовое превью.
- `nurtilek.html` — исходник (открыть в браузере, текст правится в `.title`).
- `background.png` — фон без героя и без надписи.
- `person-nurtilek.png` — фото героя без фона.

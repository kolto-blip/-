Жауап кілті

1. Google Кестені қосу (бір рет, 5 минут)

  1. sheets.new арқылы жаңа Google Кесте ашыңыз, атын қойыңыз (мысалы, «Ойын нәтижелері»).
  2. Мәзірден Кеңейтімдер → Apps Script (Extensions → Apps Script) таңдаңыз.
  3. Ашылған терезедегі барлық кодты өшіріп, төмендегі кодты қойыңыз. Сақтаңыз (💾).
  4. Жариялау → Жаңа жариялау (Deploy → New deployment). Түрі: Веб-қосымша (Web app).
  5. Орындаушы: Мен (Me). Қол жеткізу: Барлығы (Anyone). Жариялау батырмасын басыңыз да, Google рұқсат сұраса, рұқсат беріңіз.
  6. Шыққан …/exec деп аяқталатын сілтемені көшіріп, «Нәтижелер» бөліміндегі өріске қойыңыз.
// Ойын нәтижелерін Google Кестеге жинау.
// Кесте → Кеңейтімдер → Apps Script → осы кодты қойып, «Веб-қосымша» ретінде жариялаңыз.
const SHEET_NAME = 'Нәтижелер';
const HEAD = ['Уақыты', 'Ойын', 'Топ', 'Оқиға', 'Тапсырма', 'Жауап', 'Нәтиже', 'Ұпай / уақыт', 'Жалпы'];

function sheet_() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  if (!ss) throw new Error('Скрипт кестеге байланбаған. Кодты кестенің ішінен (Кеңейтімдер → Apps Script) ашылған жобаға қойыңыз.');
  let sh = ss.getSheetByName(SHEET_NAME);
  if (!sh) {
    sh = ss.insertSheet(SHEET_NAME);
    sh.appendRow(HEAD);
    sh.setFrozenRows(1);
    sh.getRange(1, 1, 1, HEAD.length).setFontWeight('bold');
  }
  return sh;
}

function json_(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj)).setMimeType(ContentService.MimeType.JSON);
}

// Ойыннан келген нәтижені жаңа жол етіп жазады
function doPost(e) {
  const lock = LockService.getScriptLock();
  try {
    const d = JSON.parse(e.postData.contents);
    lock.waitLock(10000);
    // Мәтінді «'» белгісімен жазамыз: әйтпесе кесте «00:30» мен «1/5»-ті уақыт пен күнге айналдырып жібереді
    const txt = v => (v === undefined || v === null || v === '') ? '' : "'" + String(v);
    sheet_().appendRow([
      new Date(), txt(d.game), txt(d.team), txt(d.event),
      txt(d.task), txt(d.answer), txt(d.result), txt(d.points), txt(d.total)
    ]);
    return json_({ ok: true });
  } catch (err) {
    return json_({ ok: false, error: String(err) });
  } finally {
    try { lock.releaseLock(); } catch (e2) {}
  }
}

// Мұғалім панелі нәтижелерді осы арқылы оқиды. ?test=1 болса, кестеге тексеру жолын жазады.
function doGet(e) {
  try {
    if (e && e.parameter && e.parameter.test) {
      sheet_().appendRow([new Date(), 'Тексеру', 'Мұғалім', 'Тексеру', '', '', 'байланыс бар', '', '']);
      return json_({ ok: true, test: true });
    }
    return json_(sheet_().getDataRange().getValues());
  } catch (err) {
    return json_({ ok: false, error: String(err) });
  }
}

Нәтижелер кестенің «Нәтижелер» парағына түседі. Кестені тек сіз көресіз. Сілтеме арқылы жазбаларды оқуға болатындықтан, оны оқушылардан басқа адамдарға таратпаңыз.

Жеңіс анимациясын тексеру

Ойынды тест режимінде ашыңыз: жоғарғы жағында «⏭ Финалға өту» батырмасы шығады. Ол барлық сейфті бірден ашып, жеңіс анимациясын көрсетеді. Тест режимінде нәтижелер кестеге жіберілмейді. Аватарды сейф панеліндегі ✎ белгісімен ауыстырып, әр жануарды көруге болады.

2. Оқушыларға ойын беру

А жолы, сілтеме арқылы (GitHub Pages). Ойындар GitHub-тағы docs папкасынан жарияланады. Сайт мекенжайы төменде тұр, оны өзгертпеңіз. Төменде оқушыларға арналған дайын сілтемелер шығады:

Алдымен 1-қадамдағы сілтемені және сайт мекенжайын енгізіңіз.

Ә жолы, файл арқылы (WhatsApp, Telegram). Ойын файлын мәтіндік редактормен ашып, const RESULTS_URL = ""; жолындағы тырнақшаның ішіне 1-қадамдағы сілтемені қойыңыз. Содан кейін файлды оқушыларға жіберіңіз.

Интернет уақытша болмаса, нәтижелер құрылғыда сақталып, байланыс қалпына келгенде жіберіледі.
